# Single-Input-RPE
Project repo for my UWA Computer Science Honours project. This research concerns the modification of the Reverse Prompt Engineering (RPE) system to use only a single LLM output as input for prompt extraction. The experiment files are modified versions of the original RPE experiments, which can be found here: https://github.com/hanklee97121/RPE_Reverse_Prompt_Engineering. Full implementation details can be found in my dissertation.

## Abstract
At the forefront of the Artificial Intelligence boom are Large Language Models (LLMs), allowing for natural language conversation between users and the model. The performance of these LLMs is heavily influenced by the prompts provided to the model, meaning that good-quality prompts, especially those used in commercially available LLM applications, should be kept secure. A threat to the security of these prompts are prompt extraction techniques, which allow the reverse engineering of LLM outputs into its original prompt. While several prompt extraction methods already exist, most require either large amounts of training data or need multiple LLM outputs as their input data, both of which can be challenging for real-world scenarios. The aim of this research is to investigate possible prompt extraction methods that use only a single LLM output for their input and require no training, allowing for easier use in realistic situations. Using an existing no-training prompt extraction method (known as Reverse Prompt Engineering) as the base, we implemented 4 different versions, each consisting of a different combination of 2 modifications. These modifications involved the inclusion of an additional example prompt as input along with the LLM output and the usage of a different prompt mutation algorithm inspired by Particle Swarm Optimisation (PSO). Each version was evaluated using a prompt dataset containing 6 unique prompt types to test their performance of a variety of scenarios, and to identify which improvements were most effective. We found that the experiment using only the additional example prompt performed best, while the PSO-inspired algorithm provided no clear improvements. The systems also found their best performance with short, simple question-answering prompts, but struggled with the detailed role specification prompts. The performance of all single-input prompt extraction methods was fairly poor, showing that this approach requires significant improvement to be viable in the real world.

## Usage Guide
These experiments were run using Python 3.10.0. Package requirements can be found in requirements.txt. Please note that you will need your own OpenRouter account and API key to run these experiments.
